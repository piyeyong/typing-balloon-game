# Plan: 儿童盲打气球游戏 HTML MVP

**Status:** Draft

## Goal
创建一个无需构建工具、可在本地浏览器直接打开的单页 HTML 游戏，用气球击破机制帮助儿童从英文字母开始练习规范双手盲打。

## Context
游戏不做整段文本输入。气球从屏幕底部向上飘动，显示训练目标；孩子正确输入单个字母后击破气球，气球飞出顶部则失去一颗星。累计失去三颗星后结束本局，并展示得分、击破数、最长连击和正确率。气球将随进度逐步加速。

## Scope
- 第一版仅包含小写英文字母的基准键练习：`f`、`j`、`d`、`k`、`s`、`l`、`a`。
- 仅允许一个活动气球，降低初学儿童的认知负担。
- 用内嵌 CSS/JavaScript 实现，无依赖、无服务端、无摄像头权限。
- 页面保留简化键盘与左右手提示，突出当前训练字母及推荐手指。
