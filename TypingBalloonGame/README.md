# 盲打气球大作战

一个不依赖框架、服务器或安装步骤的静态浏览器盲打小游戏。游戏使用美式 QWERTY 键盘布局，提供六种训练模式、可选错误扣分和浏览器本地排行榜。

本游戏面向使用实体键盘的桌面和笔记本电脑，不提供触摸或手机玩法。页面采用桌面优先布局：在宽度不小于 `1024px` 时，左侧栏永久显示得分、连击、失误机会、速度、当前指法提示、反馈和开始/暂停操作，右侧是气球舞台与可视键盘；舞台不会被成绩或操作覆盖。宽度低于 `1024px`（包括高缩放造成的较窄 CSS 视口）时按相同 DOM 顺序改为单列，并显示使用实体键盘、加宽窗口的提示。宽度不大于 `640px` 时，统计改为紧凑两列，操作按钮改为安全的全宽排列。

练习设置和本地排行榜分别使用原生折叠面板，首次打开页面时都保持关闭。排行榜的本地存储范围提示和存储故障信息位于折叠面板之外，因此榜单关闭时仍可看到。只有可视键盘区域会在空间不足时横向滚动；页面、侧栏和舞台本身不会成为横向滚动容器。

## 本地运行

直接双击打开 [index.html](index.html) 即可在当前版 Edge、Chrome 或 Firefox 中运行；无需 Node.js、依赖或本地服务器。

在 `file://` 下，排行榜由浏览器按浏览器、用户配置和文件 URL 保存在本机。换浏览器、换配置、移动文件或浏览器清理站点数据后，原成绩可能不可见。隐私模式或浏览器策略也可能禁止存储；这种情况下游戏仍可正常进行，成绩会保留在当前页面会话中，但刷新或关闭页面后可能消失。

## 六种训练模式

| 模式 | 训练内容 | 大小写规则 |
|---|---|---|
| 入门级 | 仅 `A S D F J K L` | 不区分大小写 |
| 26 个字母 | `a-z` | 不区分大小写 |
| 常用字符 | 小写字母、`0-9`、空格，以及 `. , ! ? ' " - : ; ( )` | 字母不区分大小写 |
| 全键盘 | 全部 95 个可打印 US-ASCII 字符（空格到 `~`） | 精确匹配 |
| 常用单词 | 适合儿童的短小常用英文单词 | 字母不区分大小写 |
| C++ 编程 | 基础符号、运算符、关键字和常用标记，例如 `;`、`{}`、`++`、`return`、`std::` | 精确匹配 |

全键盘和 C++ 等区分大小写的模式会为大写字母推荐 Shift；移位符号始终提示 Shift 并要求输入最终显示的符号。入门级、26 个字母、常用字符和常用单词模式不区分字母大小写，因此即使目标显示为大写，也不会错误提示 Shift。空格在气球和提示中显示为“空格”。

## 输入与游戏规则

1. 选择模式和是否开启“错误扣分”，然后点击“开始练习”。本轮进行中（包括暂停时）仍可切换训练模式；切换会立即放弃当前轮、清空进度并以所选模式开始一轮未暂停的新练习，不保存被放弃的成绩。错误扣分设置在一轮开始时锁定，模式切换后的新一轮沿用该设置。
2. 使用“暂停”可冻结当前气球、键盘输入和击破/飞走后的等待时间；按钮会变为“继续”，恢复后从同一目标、进度和剩余时间继续。
3. 单字符目标输入正确后立即击破；单词或标记在同一气球中逐字符推进，已完成的前缀不会因错误而清除。
4. 可输入内容是所有可打印 US-ASCII 字符，包括空格。与下一个目标字符不匹配的可打印字符算一次错误，即使它不属于当前模式。
5. 单独的修饰键、快捷键、长按重复事件、输入法组合/死键、导航键和控制键会被忽略；焦点位于选择器、按钮、输入框、原生折叠标题、链接、可编辑内容或结算对话框（包括这些控件的后代元素）时，Space/Enter 和可打印字符会操作界面而不会计入游戏输入。
6. 错误输入会中断连击，并使当前目标失去首次无错奖励。若开启错误扣分，每次错误扣 5 分，分数最低为 0；关闭时不扣分。
7. 正确完成目标保留基础分、连击倍率和整目标首次无错奖励。每完成五个目标，气球会稍微加速；较长目标会获得额外时间，最长 14 秒。
8. 气球飞走不计入正确或错误输入，但会失去一次机会；三个气球飞走后本轮结束。
9. 重新开始进行中的一轮会先请求确认；取消会保留当前活动或暂停状态，确认后开始未暂停的新一轮。未完成及因切换模式放弃的成绩都不会保存。

## 统计与准确率

- `正确输入`：每次正确推进一个字符增加一次。
- `错误输入`：每次可打印字符与下一个目标字符不匹配增加一次。
- 准确率：`正确输入 / (正确输入 + 错误输入)`；没有输入时为 0%。排行榜比较时使用未四舍五入的精确比例，界面显示整数百分比。
- 排行榜还记录得分、完成目标数、最长连击、错误输入数、飞走数和完成时间。

## 本地排行榜和结算流程

每种“训练模式 + 错误扣分开关”组合都有独立的本地前十名。榜单位于侧栏的原生折叠面板中，页面首次打开时保持关闭；即使面板处于关闭状态，保存成绩后榜单内容仍会刷新，且不会自动展开或移动焦点。

本轮结束后，在结算对话框输入昵称并选择“保存并继续”。昵称会去除首尾空白并限制为 12 个 UTF-16 字符（与输入框的 `maxlength` 一致）；留空、按 Esc 取消或选择“小玩家”继续时使用 `小玩家`。保存后会显示本轮排名，未进入前十名则显示“未进入前十名”；无论是否进榜，每个完成结果都会在当前页面会话中保留。

排行顺序依次为：

1. 得分高者优先；
2. 精确准确率高者优先；
3. 完成目标数多者优先；
4. 最长连击高者优先；
5. 错误输入少者优先；
6. 完成时间早者优先。

排行榜使用带版本号的命名空间 `localStorage` 数据。缺失、损坏、版本不符或混有无效记录的数据不会阻止游戏；有效记录会尽量保留。读取或写入失败时，页面会显示非阻塞提示，并继续使用当前页面内存榜单。

## 指法提示

游戏根据美式 QWERTY 布局高亮目标键和推荐手指。移位符号始终同时高亮 Shift 与字符键；大写字母只在区分大小写的模式中提示 Shift，不区分大小写的模式接受任意字母大小写且不提示 Shift。窄屏下可在带标签、可聚焦的键盘区域中横向滚动查看完整键盘。不同教材对少数键（例如 `B`）的手指分配可能不同，本游戏采用界面显示的固定入门分配。

## 调整窗口时的气球行为

页面使用一个持续观察舞台大小的 `ResizeObserver`，并把连续变化合并到一个动画帧中。活动气球只会在必要时被水平夹回新舞台边界；同一个 DOM 节点、垂直 CSS 动画进度、剩余时间、目标字符进度、错误状态、暂停状态和所有统计都保持不变。每次调整前都会重新核对当前回合代次与气球身份，因此重开、切换模式、击破、飞走或结束后的过期回调不会改变新回合。观察器和待处理动画帧在页面离开时进行可重复安全清理。
